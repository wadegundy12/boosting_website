Think first: why not make every tree identical?

Identical trees repeat the same error. Averaging 100 copies changes nothing. If each tree has error variance σ² and every pair has correlation ρ, the average has variance σ²[ρ + (1 − ρ)/M]. More trees reduce the independent part; lowering correlation reduces the part that survives averaging. This formula describes averaged errors, not classification accuracy directly.

0218.5.1–2 / Additive models & squared loss

Fix the flavor.
One splash at a time.

Forward stagewise modeling builds a sum. At each round, fit a new correction and add it. Previously added models and their weights stay fixed.

With squared loss, the next model learns residual = actual − current prediction. Inputs stay the same; training targets change to the residuals.

Why does fitting residuals minimize the right error?

(y − [f(x) + F(x)])² = ([y − f(x)] − F(x))². The old prediction is fixed, so learning F to predict the residual directly minimizes the new squared error. The book’s basic version uses η = 1; this lab also lets you explore shrinkage.

0318.5.3 / Exponential loss & AdaBoost

Give the tough fruit
more attention.

AdaBoost trains classifiers on weighted examples. After each round, misclassified examples gain importance. The next classifier is selected to reduce weighted error.

Then the ensemble uses a weighted vote. Good classifiers get louder votes. Example weights and classifier weights do different jobs.

Example weight = attention

The next tree minimizes the sum of weights of its mistakes, not simply the number of mistakes. Missing one high-weight example can cost more than missing several low-weight ones.

Classifier weight = voting power

β = ½ ln((1 − error) / error). An error of 20% gives β ≈ 0.693; 50% gives β = 0. The final label is the sign of the sum of β × prediction.

Where does reweighting come from?

Exponential loss is exp(−y f(x)), with y ∈ {−1, +1}. Adding βF(x) multiplies each example’s loss-weight by exp(−yβF(x)). Correct examples get multiplied by exp(−β); mistakes by exp(+β). We then normalize the weights to sum to 1. Equivalently, multiply only mistakes by exp(2β), then normalize.

0418.5.4 / LogitBoost

Less panic.
Better probabilities.

A confidently wrong prediction makes exponential loss explode. LogitBoost uses log loss, which grows roughly linearly for very wrong scores. It still cares about mistakes, without the same exponential penalty.

It fits weighted regression corrections using a Newton update: use the loss’s slope and curvature to choose the correction. Then convert the updated score to a probability.

THE TASTE TEST / move one predictionExperiment 04

Positive margin = correct side. Negative margin = wrong side. Larger absolute margins mean more confident scores.

Here exponential loss = e−m and log loss = ln(1 + e−2m), matching the book’s half-log-odds score convention. They need not have the same numeric scale.

Inside a LogitBoost round

For a 0/1 target y and current probability p, construct a working response z and a curvature weight w. Fit a tree to z with weighted least squares. Unlike AdaBoost, these weights are not simply “more weight for more mistakes.”

w = p(1 − p)   ·   z = (y − p) / w
f ← f + ½ F(x)   ·   p ← 1 / (1 + e−2f)

This calculator shows one example’s contribution, not a full training round. The tree must fit many working targets together. Near p = 0 or 1, w is small but z can be huge; implementations use numerical safeguards.

Why do slope AND curvature help?

The slope says which direction reduces loss. Curvature says how rapidly that slope changes. Newton’s method uses a local quadratic approximation to choose a step. For logistic loss this produces the working targets and weights above. A tree approximates those desired corrections across examples instead of changing every example independently.

Variance vs. bias

Random forests mainly reduce variance by averaging diverse trees. Boosting can reduce bias by adding corrections to simple models. Both affect generalization; this is a useful emphasis, not an absolute law.

Know when to stop

Choose boosting rounds using held-out validation performance. Lower training error does not guarantee lower test error. Tree depth, learning rate, and number of rounds work together.

Weak isn’t useless

A classifier slightly better than chance on the current weighted problem can contribute to boosting. The training guarantee does not mean unseen-data accuracy must improve at every round.

Scores aren’t automatically calibrated

LogitBoost directly optimizes a probabilistic log-loss objective. AdaBoost scores can be transformed into probability estimates too, but neither a sigmoid nor low classification error guarantees calibration.
